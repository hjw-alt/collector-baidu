# Shizuku 地图后台控制

源码同步日期：2026-11-23。当前源码：百度采集 App 0.1.71（com.tigercode.bdcollector）。下方验证记录保留原始测试日期与版本。

## 使用方式

1. 覆盖安装本版本采集 App，保留原有配置和记录。可按根目录 README 从源码构建安装包；本仓库不发布本地构建归档。
2. 在手机上安装并启动 Shizuku。非 root 手机重启后需重新启动 Shizuku；采集 App 会显示当前连接与授权状态。
3. 打开采集 App，点击“授权 Shizuku”，在系统授权界面允许该采集 App 使用 Shizuku。仅授权不会关闭地图。
4. 先停止本机采集，确认状态为“已连接、已授权”，再点击“关闭百度地图后台”。
5. 成功时显示“百度地图已强行停止，后台残留进程 0 个”。未连接、未授权、关闭失败或核验不完整时会显示原因。
6. 需要恢复时，可使用原有“打开百度地图”入口；继续采集仍使用原有开始按钮。

当前版本提供手动授权、状态显示和强行停止后台能力，并已接入百度设备调度轮休：连续采集两小时后释放当前任务、关闭百度地图后台并返回采集 App，等待五分钟后重新打开地图续采。手动停止后重新开始会重新计时。此流程不要求自动息屏或滑动解锁。

## 控制与核验

- 使用 Shizuku API/provider 13.1.5 的 UserService；管理器和采集 App 分别安装，分别授权。
- 本版本目标固定为 `com.baidu.BaiduMap`，不接受任意应用包名或任意命令输入。
- 用户范围从 Binder 调用方 UID 推导；仅允许 shell/root 身份执行。
- 服务依次执行 `am force-stop --user`、读取包停止状态和 `ps -A -o UID,NAME`。只有目标用户 `stopped=true` 且主进程及同包子进程均为 0，才返回成功。
- 命令有超时与输出长度上限；格式异常不会当成关闭成功。
- 手动关闭入口在正在采集或准备采集时禁用；自动轮休由采集流程先暂停并释放当前任务后执行。关闭期间禁止从界面开始采集或打开地图。
- 每次操作完成会解绑并结束临时 UserService，保留结果日志。手动关闭不会修改任务状态；自动轮休通过服务端释放接口归还当前任务。
